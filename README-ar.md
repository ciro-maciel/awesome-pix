## مكتبات مفتوحة المصدر

لإنشاء BR Code (محتوى رمز QR وخيار النسخ واللصق) وقراءته والتحقق منه دون الاعتماد على مزوّد.

- [brcode](https://go.mymarketing.click/pix-brcode) - قارئ BR Code الخاص بـ Pix مكتوب بلغة Rust. `مفتوح المصدر` `مجاني`
- [emv-qrcode](https://go.mymarketing.click/pix-emv-qrcode) - مولّد وقارئ لرموز QR بمعيار EMV مكتوب بلغة Java، وهو المعيار الذي يتبعه BR Code. `مفتوح المصدر` `مجاني`
- [go-pix](https://go.mymarketing.click/pix-go-pix) - مكتبة بلغة Go لإنشاء رمز Pix لخيار النسخ واللصق ورمز QR. `مفتوح المصدر` `مجاني`
- [php_qrcode_pix](https://go.mymarketing.click/pix-php-qrcode-pix) - إنشاء رمز QR الخاص بـ Pix بلغة PHP. `مفتوح المصدر` `مجاني`
- [PHPay](https://go.mymarketing.click/pix-phpay) - مكتبة PHP لدمج عدة مزوّدي دفع بواجهة واحدة. `مفتوح المصدر` `مجاني`
- [pix-payload](https://go.mymarketing.click/pix-pix-payload) - حزمة npm تنشئ حمولة Pix وفق معيار Banco Central. `مفتوح المصدر` `مجاني`
- [pix-utils](https://go.mymarketing.click/pix-pix-utils) - أدوات بلغة TypeScript لقراءة رموز Pix وإنشائها والتحقق منها. `مفتوح المصدر` `مجاني`
- [PIX-BACEN-SDK-dotnet](https://go.mymarketing.click/pix-pix-bacen-sdk-dotnet) - عقود واجهة Pix البرمجية من Banco Central بلغة .NET، مولّدة من المواصفات الرسمية. `مفتوح المصدر` `مجاني`
- [pypix](https://go.mymarketing.click/pix-pypix) - مكتبة Python لإنشاء BR Code ورمز QR الخاص بـ Pix. `مفتوح المصدر` `مجاني`
