## Norme e documentazione ufficiale

Ciò che viene dalla Banca Centrale, che definisce il Pix.

- [Pix no Banco Central](https://go.mymarketing.click/pix-pix-no-banco-central) - La pagina ufficiale del Pix, con cos'è, come funziona e i link al resto. `ufficiale` `gratis`
- [Normas do Pix](https://go.mymarketing.click/pix-normas-do-pix) - Il regolamento, le delibere e i manuali che disciplinano il Pix. `ufficiale` `gratis`
- [Pix Automático](https://go.mymarketing.click/pix-pix-automatico) - La modalità per gli addebiti ricorrenti autorizzati una sola volta dal pagatore. `ufficiale` `gratis`
- [Participantes do Pix](https://go.mymarketing.click/pix-participantes-do-pix) - L'elenco degli istituti che offrono il Pix e in quale modalità. `ufficiale` `gratis`
- [Estatísticas do Pix](https://go.mymarketing.click/pix-estatisticas-do-pix) - I numeri ufficiali di transazioni, importi e chiavi. `ufficiale` `gratis`
- [Perguntas frequentes do Pix](https://go.mymarketing.click/pix-perguntas-frequentes-do-pix) - Le risposte della Banca Centrale alle domande più frequenti di chi usa il Pix. `ufficiale` `gratis`

## Specifiche e API aperte

I contratti API che la Banca Centrale pubblica su GitHub.

- [API Pix](https://go.mymarketing.click/pix-api-pix) - La specifica OpenAPI dell'API Pix, che i fornitori implementano per addebiti e ricezioni. `ufficiale` `codice aperto` `API`
- [API do DICT](https://go.mymarketing.click/pix-api-do-dict) - La specifica dell'API del Directory of Transactional Account Identifiers, dove risiedono le chiavi Pix. `ufficiale` `codice aperto` `API`
- [DICT Quickstart](https://go.mymarketing.click/pix-dict-quickstart) - Una guida per i primi passi con l'API del DICT. `ufficiale` `codice aperto`

## Librerie open source

Per generare, leggere e validare il BR Code (il contenuto del QR Code e del copia e cola) senza dipendere da un provider.

- [brcode](https://go.mymarketing.click/pix-brcode) - Lettore di BR Code del Pix in Rust. `codice aperto` `gratis`
- [emv-qrcode](https://go.mymarketing.click/pix-emv-qrcode) - Generatore e lettore di QR Code nello standard EMV in Java, lo standard che segue il BR Code. `codice aperto` `gratis`
- [go-pix](https://go.mymarketing.click/pix-go-pix) - Libreria in Go per generare il Pix copia e cola e il QR Code. `codice aperto` `gratis`
- [php_qrcode_pix](https://go.mymarketing.click/pix-php-qrcode-pix) - Generazione del QR Code del Pix in PHP. `codice aperto` `gratis`
- [PHPay](https://go.mymarketing.click/pix-phpay) - Libreria PHP per integrare più provider di pagamento con la stessa interfaccia. `codice aperto` `gratis`
- [pix-payload](https://go.mymarketing.click/pix-pix-payload) - Pacchetto npm che genera il payload del Pix seguendo lo standard della Banco Central. `codice aperto` `gratis`
- [pix-utils](https://go.mymarketing.click/pix-pix-utils) - Strumenti in TypeScript per leggere, generare e validare codici Pix. `codice aperto` `gratis`
- [PIX-BACEN-SDK-dotnet](https://go.mymarketing.click/pix-pix-bacen-sdk-dotnet) - I contratti dell'API Pix del Banco Central in .NET, generati dalla specifica ufficiale. `codice aperto` `gratis`
- [pypix](https://go.mymarketing.click/pix-pypix) - Libreria in Python per generare il BR Code e il QR Code del Pix. `codice aperto` `gratis`
